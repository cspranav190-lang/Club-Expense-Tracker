💰 Club Expense Tracker

📌 Project Overview

The Club Expense Tracker is a web-based application designed to help college clubs manage and monitor their financial activities efficiently. It allows club members to record income, track expenses, monitor available balances, and maintain a transaction history.

The application provides a simple and user-friendly dashboard to make financial management easier and more transparent.

✨ Key Features

- 📊 Financial Dashboard – View total balance, income, and expenses.
- 💵 Income Management – Record funds, sponsorships, and other club income.
- 💸 Expense Management – Track club spending and purchases.
- 📝 Transaction History – View previously recorded transactions.
- 🔍 Search & Filter – Find transactions easily.
- 🗑️ Delete Transactions – Remove individual records.
- 🌙 Dark Mode – Switch between light and dark themes.
- 💾 Local Storage – Save transaction data in the browser.
- 📱 Responsive Design – Works on desktop, tablet, and mobile devices.

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open "index.html" in your browser.
5. Alternatively, use the Live Server extension in VS Code.

⚠️ Note

This project uses browser LocalStorage for storing transaction records. Data is stored locally in the browser and is not automatically synchronized between different users or devices.
